# Bundled XML schemas

The files below this folder are unmodified copies of the official XML
schemas that define CityGML 2.0, downloaded from the locations given by
their folder path (for example `schemas.opengis.net/citygml/2.0/` was
downloaded from `http://schemas.opengis.net/citygml/2.0/`). They are
included only so that `citysmith validate` can check files without an
internet connection. They are not part of CitySmith's own code and are not
covered by CitySmith's MIT license; each keeps its own copyright notice and
terms, reproduced inside the files themselves.
